# Security System - Harmful Object Detection
By Lovina Koropa

## Project Description
AI-based security system that detects harmful objects (pistol and knife) in images using YOLO World model.

## Features
- Secure login (Username: Lovina / Password: 1234)
- Detects Pistol / Gun / Handgun / Firearm
- Detects Knife
- Red alert filter on threat detection
- Threat / Safe status

## Technologies Used
- Python
- YOLOv8 World Model (ultralytics)
- Gradio
- OpenCV

## How to Run
pip install -r requirements.txt
python app.py
